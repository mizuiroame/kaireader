# Controls

[Back to the README](../README.md)

| | Library | Reading |
|---|---|---|
| **A** | Read the book (or article) selected | Next page |
| **Right**, **R**, **ZR** / **Left**, **L**, **ZL** | Move | Next / previous page |
| **Up** / **Down** | Move | Bigger / smaller text; PDFs and comics: zoom |
| **X** | The next library: SD card, network folder, book server, Free books, news | Contents and bookmarks |
| **L** / **R** | Free books: the other lists; news: one feed, or all | Previous / next page |
| **Left stick** pressed | | Bookmark the page |
| **Right stick** pressed | Upright or lying down | Upright or lying down |
| **Y** | Sort by: recent, favorites, title, author, genre (Free books: search; news: check the feeds) | Colors |
| **−** | | Show or hide the bars |
| **B** | | Back to the library |
| **+** | Menu: favorite, SD card or network folder, grid or list, look again, Settings, Exit (news: mark all as read, the next feed) | Menu: Contents, Bookmark, Library, Settings, Exit (an article: read the full article) |

The right stick moves like the D-pad. Upright, every direction turns with the
console: up is up as you hold it.

On the touch screen: tap the right or left side of the page to turn it, or
swipe; tap the middle for the bars. In the library, hold a cover to make it a
favorite. In the news, the "Refresh" at the top right checks the feeds (as
Y), and the + menu shows the next feed (as R).
